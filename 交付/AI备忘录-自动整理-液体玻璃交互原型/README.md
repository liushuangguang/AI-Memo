# AI备忘录自动整理交互原型 · 第一版

直接打开 `index.html` 即可体验，无需安装或启动服务。

## 版本定位

这是在分析旧设计意图之前完成的一套独立重构假设，用于先验证一种更克制的 AI 备忘录形态。它不会替代现有方案，也不会作为第二版的直接结论。

这一版把 AI 的内部步骤收进后台，只在记录页优先给出一句“现在最值得看什么”。原记录始终保留；AI 生成、用户采纳和写回原文是三个不同操作。

## 建议体验顺序

1. 点击首页“写一条”或底部 `+`。
2. 保存示例记录，观察多 Agent 整理和流式结果。
3. 点击“整理完成”查看每个步骤；运行中可停止。
4. 点击“采纳整理结果”，逐项选择后追加或对照替换。
5. 打开“还有 5 条相关记录”，切换关联记录、信息归类和服务建议。
6. 点击“继续问 AI”生成行动时间表。
7. 点击右上角重新整理，查看多 Agent loading。
8. 返回首页，进入“主题”查看持续聚合的信息。

## 原型边界

所有内容均为真实感模拟数据。原型不会写入真实记录、访问通讯录、请求定位或调用线上 AI。
