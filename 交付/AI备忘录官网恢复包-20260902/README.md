# AI备忘录官网恢复包

恢复日期：2026-09-02

## 结论

官网文件已经从本机仓库完整恢复。营销官网可作为纯静态站点独立运行，不再依赖原来的 Java 服务。恢复包保留首页、产品介绍、帮助中心、下载页、分享页、图片、字体、Next.js 静态资源及原 Android 安装包。

原始营销页是浏览器保存的网页快照，夹带了多个浏览器扩展的样式和界面。本恢复包只清除了这些无关代码，并把图片与安装包路径改成可独立部署的绝对路径；页面原有视觉、文案和版式未重做。

## 本机预览

在 PowerShell 中进入本目录后运行：

```powershell
.\scripts\preview.ps1
```

然后打开 <http://127.0.0.1:8766/>。

## 部署方式

最稳妥的方式是把 `site/` 上传到支持大文件的对象存储/CDN或普通云服务器。部分静态托管平台限制单文件大小，而安装包约 74 MB；若平台不接受，应把 APK 放到对象存储，并把下载地址改为对象存储 URL。

使用 Docker 时：

```bash
docker build -t ainote-website .
docker run --rm -p 8080:80 ainote-website
```

服务器对外开放 80/443 后，将域名的 `A` 记录指向服务器公网 IP，并通过托管平台、Caddy 或 Certbot 配置 HTTPS。

## 已知边界

- 首页、产品介绍、帮助中心和 APK 下载可以完全静态运行。
- `share.html` 会请求同域名的 `/note/...` 或 `/v2/note/...` 接口。要恢复“分享备忘录”动态内容，仍需同时部署 Java 后端或把这些路径反向代理到可用 API。
- 原官网的留言提交、部分页脚按钮和手机菜单本身没有完整业务逻辑；恢复包保持旧站行为，没有擅自补写新功能。
- 恢复包内置 APK 是旧官网的 2024 年版本。`交付` 目录另有 2026-09-02 新 APK，如需替换，应先确认哪一份是正式生产版。
