# AI 备忘录 · 产品背后的故事

独立的中文产品设计故事网站。原官网及旧案例页保持独立。

## 叙事

主线：一句随手记录，怎样继续发挥价值。公开主文保持简短；详细取舍、来源和验证边界收进可展开的阅读层。

包含首页角色分工、截图确认、信息补全、AI 结果分层、建议选择、主题合并、保存可靠性、商业假设、埋点与后台、国际化方向。

网页中的搬家示例是固定数据，不调用 AI，不读取或上传访客笔记，也不在浏览器持久保存示例输入。

## 运行

使用 npm 与项目锁文件，推荐 Node 22.22.0（见 `.node-version`）。`npm ci` 后，运行 `npm run dev -- --port 3016`。本机 Node 24 的打包进程退出触发了 Windows libuv 断言；改用 Node 22.22.0 已正常完成。也可运行 `npm exec --yes --package=node@22.22.0 -- node node_modules/vinext/dist/cli.js build`。

`npm run build` 导出静态网站到 `dist/client`。部署只需要公开静态输出，无数据库、API 密钥或模型调用。

## 内容边界

设计初衷取自原始项目演讲、商业材料和当前 Figma。实现状态核对到 0.1.3 / build 5 的 2026-09-06 交付说明及源码。Figma 设计版本和 App 构建版本分别说明。

付费、完整埋点后台和国际化为待验证方案。未使用历史商业计划里的目标用户数、收入目标或未经核实的收益。未把代码测试当作真机验收或真实用户价值。

待作者校准：第一人称表达、主线轻重、商业内容公开程度。当前采用“把复杂 AI 能力做成普通人愿意用的产品”的叙事主线。

## 第二版：连贯叙事与动效

保留蓝白配色、产品证据、三个核心交互示例及所有专业详情。用同一条搬家记录串联首页、补问、结果取舍、旧记录连接和可靠性。新增周四/周六场景切换、搬家 SVG 插画、完整界面画廊、章节阅读进度和收尾便笺。

动效由 CSS、SVG 与浏览器原生滚动动画组成，没有新增运行依赖。滚动动画不受支持时保留完整静态排版；页面提供暂停入口，遵循系统减少动态效果设置。插画用于解释故事，产品图继续使用此前核对的四张完整 Figma 导出，不伪装成真机截图。

第二版验证范围：类型检查、代码检查、静态构建、资源引用和锚点、图片尺寸与文件哈希。没有执行浏览器截图或交互验收。

## 第三版：四幅插画与五处机制动画

四张原生 1536×1024 的 AI 纸雕配图承接每次故事转折，图片完整展示并按需加载。五处 SVG 图分别解释截图确认、私人背景补问、信息分层、主题来源和失败恢复，动画跟随读者选择及确认状态。手机采用紧凑图解，保留暂停动效及系统减少动态效果支持。

用分层动画替换重复静态说明，维持短正文与按需深入阅读。真实 UI 资产与事实依据沿用此前核对结果；新增插画与预设演示未增加产品实现承诺。详见 `ARTWORK.md` 和 `art-manifest.json`。
