## AI 叙事配图

2026-09-06 使用 Codex 内置图像生成工具制作四张独立配图。原生尺寸均为 **1536 × 1024，3:2**，已读取 PNG 文件头核对；未裁剪、未放大、未做尺寸后处理。原始生成文件保留，站内文件是原图的逐字节副本。尺寸、大小和 SHA-256 见 `art-manifest.json`。

| 文件 | 叙事用途 | 场景 |
| --- | --- | --- |
| `public/art/scattered.png` | 从留下内容，转向理解内容 | 搬家纸箱、散落便笺、相片与纸狗 |

共用视觉约束：编辑性纸雕静物；冷白、钴蓝、深墨色；少量自然纸箱色；柔和侧光、真实哑光纸张和铅笔细节。完整构图，不绘制产品 UI、品牌标志或可读文字，不加入机器人、霓虹光效。场景描述为提示词摘要。

插画属于产品故事的视觉比喻，配有「AI 叙事配图」说明。图中纸张、照片和人物手部均为生成内容，不是实际用户资料。产品 UI 继续使用已核对的完整 Figma V2 导出，见 `asset-manifest.json`。

## 五处 SVG 机制图

| 位置 | 读者可以看到的变化 | 静态与失败处理 |
| --- | --- | --- |
| 截图记录 | 确认后点亮第一段连接、扫描示意图；模拟生成后点亮结果 | 确认前不展示已完成；可重新演示；无上传 |
| 信息补全 | 点选身份后点亮对应分支，确认后显示完成标记 | 保留原词时不填充私人事实；手动输入留在当前页面 |
| 结果分层 | 一条记录分向四类用途，采纳数量随复选框更新 | 选择和确认保持区分，原文一直保留 |
| 主题合并 | 所选来源连接到主题，合并后点亮结果；回看来源时显示回流路径 | 未选来源继续保留；至少两个来源才可合并 |
| 放心使用 | 在晚到结果和失败重试场景间切换 | 原记录和新结果分开；重试只作用于网页预设示例 |

动效通过 SVG 路径和 CSS 实现，按视口可见性触发，复用全站「暂停动效」与系统减少动态效果设置。所有图的默认状态均可读；关闭动态效果不会遮住内容。未新增动画运行依赖。

验证范围：类型与代码检查、静态构建、资源与锚点、四张原 UI 的哈希和四张新图的尺寸。未执行浏览器截图或操作验收。
